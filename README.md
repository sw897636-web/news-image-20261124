## How dates are shown

The masthead reads "TUESDAY 24 NOVEMBER 2026" with the subline "Overnight Monday → Tuesday · each story dated". Every story cell carries a date chip in its top-left corner that names the day and the region together (for example "MON · USA"). Tuesday chips are red, Monday chips are grey-blue, and the Sunday-night chip is grey. Only the two Tuesday stories are dated Tuesday; the five Monday stories and the Sunday-night concert are dated as such, so no Monday event is presented as happening on Tuesday.

## How it works

`main.ts` (Node 22, standard library only) copies `entry.png` to the output directory (`$MAKEFUN_OUTPUT_DIR`, default `/output`). The copy is byte-for-byte, so two runs produce identical output.
