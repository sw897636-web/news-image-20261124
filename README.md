A single 1024×1024 infographic summing up the world's news of **Tuesday 24 November 2026** — an entry for the [make.fun bounty](https://make.fun/bounty/news-image-20261124).

Eight stories in one picture: Ukraine confirms the sinking of a Russian warship off Libya; Nvidia brings Jensen Huang back as CEO; Iran resumes strikes on US bases in the Gulf; the UN chief urges a global AI safety framework within a year; Belgium's nationwide strike; 12,000 people evacuated from a Manchester concert on Sunday night; the UK confirmed as host of the 2035 Women's World Cup; and Tuesday-morning crypto prices (BTC $61,194, ETH $1,709).

## How it works

`main.ts` (Node 22, standard library only) copies `entry.png` to the output directory (`$MAKEFUN_OUTPUT_DIR`, default `/output`). The copy is byte-for-byte, so two runs produce identical output.

## Files

- `main.ts` — the entry program
- `entry.png` — the 1024×1024 infographic (676,605 bytes)
- `LICENSE` — MIT

## Sources

BBC, The Guardian, France 24, Al Jazeera, CoinGecko. Monday events are labelled Monday / Sunday night, as reported; the crypto prices are Tuesday Asia-morning figures.
